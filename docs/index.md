# nas200-reborn

This documentation prepares a measured Raspberry Pi 3 rebuild of the Linksys
NAS200. It is not yet a finished builder guide.

- [Hardware baseline](hardware.md)
- [Software baseline](software.md)
- [References](references.md)

Every claim is documented, measured, proposed, or prohibited. Proposed wiring
must not be used as a build instruction until donor evidence validates it.
