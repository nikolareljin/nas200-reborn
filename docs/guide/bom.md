# BOM constraints

The BOM defines selection constraints. Record quantity, manufacturer part
number, electrical and mechanical constraints, vendor URL, price, retrieval
date, substitute policy, and validation status for each selected part.

| Item | Qty | Required specification |
|---|---:|---|
| Raspberry Pi 3 Model B | 1 | Genuine board with working Ethernet and 40-pin header |
| Boot media | 1 | Endurance-rated microSD, at least 32 GB |
| SATA-to-USB bridge | 2 | 3.5-inch SATA, external power, Linux and SMART validation |
| 12 V to 5 V buck | 1 | Regulated 5 V, at least 5 A continuous |
| Input and branch fuses | 1 set | DC-rated holders and measured values |
| SATA harness | 1 set | 12 V, 5 V, and ground to each drive |
| Pi lead | 1 | Fused, strain relieved, verified polarity |
| Bracket material | 1 set | Insulating, heat-tolerant, measured fit |

Reject damaged connectors, unmarked converters, undersized wire, no-name
adapters without current ratings, counterfeit boards, and bridges that cannot
expose a reliable device identity.
