# Software baseline

Use 64-bit Raspberry Pi OS Lite, OpenMediaVault, Samba, smartmontools, and a
local GPIO service. Choose either separate ext4 disks or mdadm RAID1 after
completing the hardware checks.

Do not use an unreviewed remote installer pipeline. Pin the operating-system
image checksum, OpenMediaVault release, and configuration revisions.
